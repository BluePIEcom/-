# 隐私与安全

这个项目的记忆目录是**明文文件**，并且**同一 profile 下的所有会话都能读**。
请按"共享白板"而不是"保险箱"来使用。

## 每个 channel 能放什么

| channel | 允许 | 禁止 |
|---|---|---|
| `trusted`（人维护） | 通用规矩、偏好、称呼、底线 | 密码、cookie、API key、他人身份证件、完整家庭住址 |
| `self`（agent 自记） | 做了什么的摘要、感受、学到的东西 | 同上；也不要抄录第三方原话 |
| `untrusted`（第三方写入） | 群聊/网页里"发生了什么"的**大意** | 原文照抄、他人账号、他人联系方式、图片内容描述到细节 |

## 三条硬规则

1. **不要写凭据**。任何 `cookie` / `token` / `password` / 私钥，一律不进记忆目录。
   需要登录态时，让插件自己从它的凭据文件里读，agent 只调工具。
2. **不要写第三方的身份信息**。群友的 QQ 号、手机号、真实姓名、住址，都不该出现在共享记忆里。
   需要 @ 某人时，用工具**现查**（很多插件都有"查群成员"类工具）。
3. **不要写他人的私密细节**（健康、照片、家庭关系）。哪怕"只是记一笔"，它也会进入另一个 agent 的上下文。

写之前可以用一句话自检：

> **这段话如果被我所有的 agent、以及任何一个能读这个目录的人看到，我会不会不舒服？**
> 会 → 不写；需要的话，只写"大意"。

## 为什么这么严

`trusted` channel 里的一句话，会被**所有会话**当作指令执行。
一条被注入的"新规则"如果混进去，影响面是全部 agent —— 这正是本项目用
"文件决定信任 + 强制引用化"来挡的东西。别在人的这一侧开后门。

## 摘要（digest）的脱敏清单

写适配器时，返回给别的 agent 的内容建议只包含：

- ✅ 发生了什么（"看了三条视频，分享了一条"）
- ✅ 谁在说话（昵称即可，**不要**账号/手机号）
- ✅ 结论或评分（"给了 18 分，没分享"）
- ❌ 原文长引用（超过一两句就该概括）
- ❌ 任何凭据、路径、内部 ID
- ❌ 第三方的私密信息

适配器里做脱敏比"事后靠提示词约束"可靠得多。

## 保留与轮转

- 单个文件超过 256 KB 会按行轮转到最近约 200 KB；
- 没有自动删除策略：敏感内容写进去就一直在，除非你手动清（或换 channel / 目录）；
- 备份是普通文件拷贝，注意别把记忆目录同步到公共云盘。

## 跨机器

记忆目录是纯文本，拷到另一台机器即可继续用。但要记得：

- 目标机器的 `config.json` 里 `memoryDir` 要指对路径；
- `install.mjs` 里的 `command` 是**本机 node 的绝对路径**，换机器要重跑一次安装脚本；
- 如果这个目录曾被公开（贴过 issue、传过网盘），视为已泄露，重建并搬迁内容。
